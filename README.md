# sangat-poster-generator

## Deployment

The site is published to [GitHub Pages](https://arshreality.github.io/sangat-poster-generator/) by the workflow in `.github/workflows/pages.yml` whenever changes are pushed to `main`. The workflow uploads the static site directly from the repository root; no build step is required.

For the first deployment, make sure GitHub Pages is enabled for the repository with **Settings → Pages → Build and deployment → Source** set to **GitHub Actions**. You can also start a deployment manually from the workflow's **Run workflow** button in the Actions tab.
